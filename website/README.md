# 映畫竹塹｜新竹城市影像與旅行網站原型

純 HTML、CSS、JavaScript 與 jQuery 的多頁網站原型。每個主題頁、內容詳情頁與管理後台頁面都是獨立 HTML，可直接以靜態伺服器或瀏覽器開啟。

## 網站結構

- `index.html`：首頁與新竹市影像博物館主視覺。
- `explore.html`：城市散策、景點、美食與在地店家搜尋與篩選；優惠另設獨立專區。
- `cinema.html`：本週映演片單。
- `events.html`：新竹活動與城市消息。店家優惠獨立管理。
- `planner.html`：會員行程安排。
- `food.html`、`offers.html`、`activities.html`、`city-news.html`、`routes.html`、`search.html`：美食、店家優惠、活動、城市消息、推薦行程與搜尋等獨立主題頁。
- `login.html`、`register.html`：獨立會員登入與註冊頁。
- `museum.html`：新竹市影像博物館獨立詳情頁。
- `places/`：東門市場、或者工藝櫥窗、新竹公園、咖啡與選物店詳情頁。
- `films/`：各部預設電影的獨立詳情頁；`film-detail.html` 提供後台新增電影的獨立詳情展示頁。
- `news/`：活動與城市消息的獨立詳情頁；`news-detail.html` 提供後台新增消息的獨立詳情展示頁。
- `offers/`：每筆預設優惠各有獨立詳情 HTML；後台新增的優惠使用獨立 `offer-detail.html?id=...` 詳情頁。
- admin/：後台獨立頁面，包含儀表板、景點與店家、本週映演、消息活動、獨立店家優惠、推薦行程、會員管理與網站設定。優惠清單、`offer-add.html`、`offer-edit.html` 分別是獨立頁面；新增、編輯與刪除操作只寫入 `yinghuaAdminOffers`。景點、映演、消息與推薦行程也使用各自獨立新增／編輯頁面。刪除由列表確認後直接移除並顯示通知，不另設刪除頁。
- `css/style.css`：全站獨立樣式，含 RWD、鍵盤焦點及減少動態偏好。
- `js/app.js`：前台操作與後台示範資料互動。
- `docs/ENGINEERING-HANDOFF.md`：建議資料表、API 與安全串接方式。

## 示範操作

1. 從首頁導覽進入各獨立主題頁，再由內容卡片進入各自的 HTML 詳情頁。
2. 城市散策支援類別、區域、關鍵字篩選、跨內容搜尋、可保存的收藏與加入行程；加入網站現有景點會存進行程清單，新建立的後台景點亦會出現在前台示範清單。景點詳情頁也能直接把該地點加進行程。
3. 旅行計畫支援調整順序、移除地點、設定行程名稱與日期、套用前台／後台推薦路線；資料暫存於瀏覽器 `localStorage`。
4. 後台各項目可由 `admin/` 的左側導覽獨立開啟，手機版可展開側欄。景點、映演、消息、店家優惠與推薦路線有獨立新增／編輯頁，列表可編輯與確認刪除。會員清單支援篩選，網站設定可儲存。景點新增頁可選用既有示範景點資料，模擬短網址解析後帶入表單。
5. 會員註冊／登入、隨機驗證碼、收藏、行程與後台新增／編輯／刪除均為瀏覽器端操作示範；資料存於 `localStorage`，不同裝置與瀏覽器不會同步。詳情以獨立 HTML 頁開啟，不使用燈箱；電影、消息、景點與店家優惠詳情頁會依主題清單顯示上一篇／下一篇縮圖與標題。

正式上線前，請改接後端 API、資料庫、會員驗證與權限系統。Google 地圖短網址解析目前只會帶入使用者所選的既有示範景點，不會呼叫 Google；正式版需由伺服器端安全展開並呼叫 Places API，不可將私密 API 金鑰放在前端。外部圖片與字型目前為示意資源，商用請替換成具合法授權的素材。
