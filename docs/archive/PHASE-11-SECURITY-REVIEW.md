# 階段十一會員API安全審查

2026-10-31；使用security-audit skill，限定本次會員完整行程、公開路線預覽、前端狀態與共用接入。無新認證機制、外部傳輸或主庫帳號變更。

| 邊界 | 審查及實測 |
| --- | --- |
| BOLA／所有權 | Kernel強制member namespace；Service重查有效會員，Repository每次帶member_id。A讀改刪選擇／套用B為404，admin Cookie為401，客戶端memberId拒絕422。 |
| CSRF／大量賦值 | 沿用共用Cookie／CSRF及JSON容量；無CSRF寫入403。DTO白名單、明確型別及UUID／日期／時間格式，不接收status／deletedAt／任意欄位。 |
| 交易並行 | 鎖會員再鎖行程、固定景點ID順序；同版全量更新一200一409。注入子表失敗後主檔、版本及全部站點回滾。版本跨同會員所有歷史行程遞增，P0舊分頁不能誤改新current。 |
| 去重／私人資料 | POST同UUID只載本人結果，不覆寫、不重複建立；其他會員同ID409。輸出DTO不含memberId／session。成功後再次查身分，身分換人清草稿；同人401草稿保留且不自動重送。 |
| 公開資料 | 只使用成功快照，路線套用鎖定後比對即時主檔與成功投影；草稿、無可用站拒絕。新站即時驗可用，舊站只保留既有快照，不拿後台私稿補介紹。 |
| SQL／XSS | SQL全綁參數，排序固定。文字經textContent／原生value；公開卡片轉義，網址只取公開投影。沒有innerHTML插入會員名稱或備註。 |
| UX失敗邊界 | 409與網路結果不確定保留草稿、禁止盲重送；新建持有UUID直到確定結果。刪除及路線替換先確認；GET不自動寫會員。 |
| 環境／秘密 | .env仍忽略，測試manifest／密碼／截圖不提交。只用自有yinghua_test資料，測後清內容、停用帳號、撤銷session，稽核歷史保留。無新依賴、容器或權限擴張。 |

證據：81項真實整合、66契約回應、P0收藏69／目前行程100、107 PHP／208 JS、PHPStan／PHPat及本機Browser身分切換／雙分頁衝突通過。新程式沒有需另行處理的已知安全失敗；這是限定範圍結果，不代表正式環境滲透測試。未重跑Semgrep、Gitleaks、容器映像／依賴全掃描；前階段正式交接差項不因此關閉。AA有效共用基線與增量範圍見[驗收](PHASE-11-ACCEPTANCE.md)。
