# Excel逐列重驗與介面一致性檢查（2026-11-02）

依使用者U-24指示：以原始 `映畫竹塹_後台工程串接功能規格.xlsx`「功能規格」E5:L34 共30列為基準逐列實測，並以客戶原型 `website/` 對照 `frontend/`，檢查操作邏輯、美觀，以及欄位／介面字級與高度不一致（忽大忽小）。本輪在本機Docker環境（`localhost:8080`）以Playwright實際操作，原型以靜態方式在 `localhost:8090` 開啟對照。正式網域、HTTPS、外部平台與完整AA讀屏仍依既有交接，不在本輪冒稱通過。

## 方法

- 介面量測：69個固定頁（含新404頁）＋後台22頁，於1440／390／320三種寬度截圖並量測每個可見輸入／下拉／按鈕的高度與字級、水平溢出及主控台錯誤；原型同頁同尺寸對照。
- 功能：公開列（5–18、29–34）與後台列（19–28、32）分別以真瀏覽器＋HTTP逐項操作E功能／G限制／L驗收；測試資料使用 `qa-a-`／`qa-b-`／`qa-ui-` 前綴，結束後刪除或軟刪除（後台設計保留軟刪除列與稽核紀錄）。
- 自動測試：前端 Docker 全套、PHPUnit、PHPStan。

## 介面一致性：發現與修正

| 問題 | 原因 | 修正 |
| --- | --- | --- |
| 後台同一列文字欄49px、下拉45px、日期時間51px，底線不齊 | 各控制項沿用瀏覽器預設高度（原型亦然） | `ui-consistency.css` 統一單行欄位與同列按鈕為48px；三尺寸量測後台全部頁面單一高度 |

## 保留事項（未修改，供決定）

以下為原型既有行為或屬業務決定，依規格基準不自行改變：

- 消息新增預設「發布／排程」，與原型「立即發布」一致；景點／電影／路線預設草稿。
- 電影／消息詳情頁「安排進旅行 →」只連到行程頁（原型行為），與景點頁「加入行程」不同。
- 景點列表篩選條件未寫入網址；美食頁沿用原型分類標籤。
- `events.html?type=city|event` 與 `city-news.html`／`activities.html` 內容重疊且皆可索引（既有SEO設計）。
- 刪除後的管理員帳號／Email不可重用（唯一性含軟刪除列）；合作店家沒有刪除功能。
- 權限頁對操作者無法授出的權限仍顯示可勾選，儲存時才403。
- 編輯後導回列表不保留原搜尋條件（管理員列表除外）。
