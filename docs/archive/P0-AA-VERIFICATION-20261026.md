## 尚未通過的兩項

### AA-01：登入到期前缺少提示／延長

使用具名 `yinghua_test` 管理員，在自有景點輸入未儲存摘要，再只將該帳號 session 的閒置期限設為過期。儲存被正確拒絕，資料庫摘要不變；現有 beforeunload 提示可取消離頁，取消後原文字仍在。**本輪沒有證據顯示必然遺失內容，不將其誤寫成資料遺失缺陷。**

不通過原因是既有 `AUTH_IDLE_SECONDS=1800`／`AUTH_SESSION_SECONDS=43200` 沒有到期前可操作警示與延長機制，不能只以「安全 session」主張符合 [2.2.1](https://www.w3.org/WAI/WCAG21/Understanding/timing-adjustable.html)。現有跳登入與未儲存警告也不等同預先給足延長時間。

修正方案待實作：API 回傳明確到期資訊；共用前端在到期前提示；閒置延長由仍有效的驗證請求完成，達絕對上限則重新認證並保留目前表單，不延長或停用既有安全上限。相關 session／CSRF／失效／越權及多次延長需真 MariaDB 與瀏覽器重新驗證。**本輪未改 PHP、session 期限或安全設定。**

### AA-02：已發布非當週電影缺少完整尋找途徑

只把本輪自有電影的兩個場次移到 14 天前，保持 published；同步測試發布版後，真實瀏覽器得到：

| 路徑 | 結果 |
| --- | --- |
| 直接開啟該電影 slug 詳情頁 | 可讀，標題正確 |
| 首頁 | 沒有該電影 |
| 本週映演 | 沒有該電影，符合當週篩選本意 |
| 搜尋該電影完整名稱 | 無結果，目前搜尋使用原型示範陣列 |

不存在可涵蓋這筆已發布內容的完整導覽索引。不能把「可直接貼網址」算成使用者可尋找內容的第二種方式；依 [2.4.5](https://www.w3.org/WAI/WCAG21/Understanding/multiple-ways.html) 判為不通過。

修正方案待實作：P0 最小可存取的公開內容索引／網站導覽，與公開發布白名單同源，含所有仍發布的內容及其分類／詳情連結，再搭配既有分類導覽；不提前冒充 P2 的完整搜尋。正式新增頁面時須同步更新發布失敗／下架／排程、SEO 與導讀。此處是修正方案，不寫成已完成功能。
