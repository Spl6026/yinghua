1. 確認 Git 原始交付、Docker／PHP／MariaDB、主庫與隔離庫邊界、初始化／升級及品質工具。

- 21 套階段二至四整合：全部通過。獨立 JSON Schema 驗證觀察到 54 個操作、788 個 HTTP 回應及 260 個成功 JSON 請求，零契約差異。
- PHP 64 項／263 斷言、PHPStan level 10／PHPat 通過；前端 102 項通過，包含本輪空值 HTML 產生回歸。
- 空庫及保留資料升級：階段五 28 表／15 migration；固定階段四歷史基準 24 表／12 migration。舊會員／景點／店家保留，臨時測試庫清理。
- 階段五消息 40、優惠 40、首頁 21、安全 27、demo 10、容器重建 9、跨日發布 20、交易回滾 11 項通過；消息／優惠另驗證 12／8 個回應 schema。SMTP 故障／復原四項通過，Mailpit 已復原。
- Composer strict validate、platform requirements、應用及工具 lock audit、197 檔格式 dry-run、主／測試 Nginx 配置通過。Rector 僅 dry-run，29 檔風格建議已檢視未套用；exit 2 表示有建議，不寫成零差異。
- 實際 MariaDB 12.3.3 的公開消息／優惠查詢執行 EXPLAIN／ANALYZE；沿用 publication 索引，關聯使用主鍵。Performance Schema 為 OFF，沒有為本輪檢查重啟共用 DB，也不把少量 demo 的結果當成負載保證。

## 介面對照及實際操作

前台 14 頁：首頁、城市散策、美食、片單、新竹現場、城市消息、優惠、博物館、景點詳情、電影詳情、消息詳情、優惠詳情、登入、註冊。每頁分桌面／手機、原型／新版共 56 筆量測。新版未見頁面水平溢出。

後台七頁：電影列表／新增、景點列表／新增、管理員列表／新增、權限矩陣。每頁同樣分四種情境，共 28 筆量測；另操作景點／電影／管理員編輯、更改密碼返回頁及唯讀預覽。原型手機權限頁可溢出，新版以表格自己的捲動區處理。側欄、頂列、雙欄／手機單欄、原型 CSS 與主要區塊沿用，API 所需狀態／發布／多場次欄位造成的高度差異保留。

實際瀏覽器操作：

- 匿名後台導向登入，登入保留電影列表 returnTo；更改密碼頁「回後台」導向可用後台，不執行更改密碼。
- 管理員編輯名稱保存；固定 root 矩陣 40 格全勾選且停用。
- 唯讀模擬可見雙身分；無權限頁仍可退出。沿用既有具電影 view／edit 的測試身分，編輯頁可讀兩場資料、可編輯輸入數為 0、儲存停用。
- 手機景點搜尋、導覽開關與 Escape；人工景點 Google 關聯區隱藏。僅填名稱及週表可存草稿，摘要／介紹留空；重開保留週一時段與週二公休，再發布到前台。
- 電影新增兩場相同時間，API 拒絕並聚焦第二列日期；改成兩個不同分鐘後可存。原生檔案選擇器選自有 PNG、上傳 120×180 海報並發布；後台、片單及詳情均有兩場。
- 註冊提交、驗證碼／重設、密碼變更與權限寫入的成功／拒絕由整合測試驗證，不冒稱全部經瀏覽器手動送出。

量測與截圖在忽略的 `artifacts/review-phases1-5-ui/`，契約及套件日誌在 `artifacts/`。這是代表頁的結構、尺寸、顯示與操作複驗，不是全站逐像素、所有瀏覽器或完整 WCAG 認證。

## 安全邊界與收尾

自動核准審查曾拒絕替新測試帳號增授電影 edit；該命令未執行，改用既有有權限的身分做唯讀模擬，沒有繞過審查或修改該身分權限。這輪自己的景點、電影、管理員已透過正常 API 刪除；軟刪與 append-only 稽核保留，不清空既有測試庫。

Windows 防毒先前隔離的 skill 參考檔刪除不納入提交、不還原。`.env`、測試憑證、截圖、大型歷史備份不提交。正式 HTTPS／SMTP、Google 正式配額、內容與圖片權利及全站可及性不因本機測試而視為完成。
