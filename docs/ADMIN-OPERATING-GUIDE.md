# 後台操作手冊

2026-11-01。網站實際功能以[全站導讀](PROJECT-GUIDE.md)及[30項矩陣](DELIVERY-ACCEPTANCE-MATRIX.md)為準；以下不包含尚未確認的正式網域、素材或第三方平台操作。

## 登入與權限

本機主站後台為`http://localhost:8080/admin/login.html`；8081是隔離驗收站。固定帳號admin由部署人員初始化，密碼僅保留於本機受保護設定或安全管理工具，不在本文件列出。總覽及各功能依本人權限顯示；網址能開啟不表示API允許操作。

管理員管理可維護一般帳號；固定root無編輯刪除入口。權限設定按人、模組、view/create/edit/delete保存。root模擬身分只供唯讀驗收，不能保存或刪除內容。會員查詢只顯示遮罩資料及唯讀摘要，沒有會員新增／刪除／匯出功能。

## 景點與地圖

進入景點清單新增或編輯，可人工填寫或貼Google Maps HTTPS網址，解析後確認預填欄位再儲存；解析不會自動建檔。Google官方簡介僅供原文參考，網站介紹由管理員填寫。營業時間使用共用每週時段編輯，未知時間可留空，不自行假設全天開放。摘要／介紹依目前規格選填，尚未實作自動補位。

圖片依用途填替代文字，純裝飾依實際用途處理；系統做圖片內容檢查／重編碼，沒有病毒掃描服務。Google配額、API啟用與正式金鑰限制需由正式服務管理者確認。

## 電影、消息、優惠與推薦路線

電影維護介紹、海報與多筆放映日期／開始時間；同日期同開始時間會檢查重複。依使用者指定，結束時間／場地衝突不是本版規則。消息區分活動與城市消息；優惠獨立維護店家、有效期間及必填條款，不會進消息列表。推薦路線依站點順序顯示；發布需有有效景點，下架景點不會新增到會員行程。

**草稿要發布**：開啟該筆編輯頁，把狀態改為「已發布」，依表單填寫或確認發布時間，再按儲存。未到排程時間不會提前公開。看到儲存成功但發布待重試時，先依提示重新整理或請維運檢查publisher，不連續重送造成版本衝突。

刪除會先確認並檢查關聯；不另開刪除頁。遇到409表示資料已被其他視窗更新，現有草稿保留；先核對再明確重新載入，不要用舊版本強覆蓋。

## 網站設定

「基本網站資訊與政策」管理網站名稱、摘要、聯絡信箱、條款及隱私文字／版本。「SEO」管理共用及逐頁標籤、分享圖、robots及驗證碼。兩區有版本檢查；另一區保存後，重新讀取再修改可以避免過期版本。政策改動會更新後續註冊同意版本；聯絡信箱改動不會無故更新同意摘要。政策文字是純文字，不執行HTML。

正式站名稱、條款內容、聯絡資訊及SEO origin須由業主確認，不把本機示範文字當正式內容。

## 會員行程

會員在旅行計畫選擇或新增本人行程，同頁「新增地點」搜尋加入草稿；調整順序、時間及備註後按「儲存行程」。重新登入可載回伺服器資料。套用推薦路線前會確認，替換不會靜默執行。未儲存變更離開前有提醒；其他帳號不能讀寫本人行程。

## 日常檢查

總覽顯示本人有權檢視模組的未刪除總數與最近更新，不是月成長或瀏覽量。root稽核僅顯示必要識別，沒有before/after全文或IP。需要診斷時記錄畫面錯誤與requestId，不貼密碼、token、Google金鑰或整份資料庫。發布、備份、還原及停機操作交給有部署權限者，依[維運手冊](P0-OPERATIONS.md)執行。
